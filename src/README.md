# Source Code

This directory contains the two main processing components
of the Multi-Source Data Processing Automation System.

## Components

- [`component_A_source_management/`](component_A_source_management/)  
  Manages source data and generates structured JSON datasets

- [`component_B_matching_analysis/`](component_B_matching_analysis/)  
  Handles participant matching, progression tracking, and analysis

## Implementation Notes

Both components are implemented in Google Apps Script.
Source code is not published in this repository
as it contains internal operational data.
